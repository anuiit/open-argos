# Research profiles

## Docs

Use `--profile docs` for official documentation, API/SDK usage, configuration,
compatibility, migration guides, release notes, and known limitations.

## Landscape

Use `--profile landscape` for alternatives, trade-offs, maturity, maintenance,
adoption, licensing, ecosystem fit, and switching costs.

## Implementation

Use `--profile implementation` for reference architectures, production case
studies, maintained repositories, examples, operational pitfalls, and
performance behavior.

## Current

Use `--profile current` for recent versions, changelogs, security advisories,
open issues, deprecations, roadmaps, and time-sensitive behavior.

## Evidence

Use `--profile evidence` for papers, standards, benchmarks, replication,
methodological comparisons, and scientific uncertainty.

## Deep

Use `--profile deep` to combine documentation, landscape, implementation,
current, and academic evidence for a high-impact decision. Make conflicting
source incentives explicit.

## Decision record

Record:

- question and affected decision;
- impact if the working assumption is false;
- sources, dates, and relevant versions;
- findings and alternatives;
- contradictions or missing evidence;
- conclusion and confidence;
- when the evidence should be refreshed.
